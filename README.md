OneInfer provides a production‑grade AI inference platform available as a cloud service or deployable in‑house. It offers a unified OpenAI‑compatible API for text, vision, audio and video models from multiple providers, with routing, kernel optimization, and pay‑as‑you‑go pricing. The platform includes OneInfer Voice, Studio, Aura, and private‑cloud options for enterprises.

**Areas:** AI · Inference · Cloud · Platform · OpenAI-compatible

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OneInfer: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
